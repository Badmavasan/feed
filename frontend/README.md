# Feedback Management Interface

Ce projet est une interface de gestion de feedbacks développée avec **Next.js** et **Chakra UI**, dans le cadre d'un système de gestion pédagogique.

## Installer les dépendances

npm install

## Démarrer le serveur local
npm run dev
L'application sera accessible à l'adresse :
http://localhost:3000

## Structure des pages
/login : page de connexion
/dashboard : tableau de bord avec accès à tous les modules
/type, /erreur, /exercice, /composant, /feedback, /mes-demandes : modules CRUD
